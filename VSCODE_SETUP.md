# Running SoundWave in VS Code\n\n## Prerequisites\n\nBefore starting, ensure you have installed:\n\n1. **VS Code** - Download from https://code.visualstudio.com/\n2. **Node.js** (v16+) - https://nodejs.org/\n3. **Git** - https://git-scm.com/\n4. **PostgreSQL** (v12+) - https://www.postgresql.org/download/\n5. **Redis** - https://redis.io/download (or use Docker)\n6. **Python** (v3.9+) - https://www.python.org/downloads/\n\n## Verify Installations\n\nOpen VS Code Terminal (Ctrl+` or View → Terminal) and run:\n\n```bash\nnode --version       # Should show v16+\nnpm --version       # Should show 8+\npython --version    # Should show 3.9+\ngit --version       # Should show git version\npsql --version      # Should show PostgreSQL version\nredis-cli --version # Should show Redis version\n```\n\n## Step 1: Clone Repository\n\n```bash\n# Option 1: Using VS Code\n# 1. Press Ctrl+Shift+P\n# 2. Type \"Git: Clone\"\n# 3. Paste: https://github.com/Ujwal8156v/soundwave-musicstream-app.git\n# 4. Select folder to clone into\n\n# Option 2: Using Terminal\ngit clone https://github.com/Ujwal8156v/soundwave-musicstream-app.git\ncd soundwave-musicstream-app\n```\n\n## Step 2: Install VS Code Extensions\n\nOpen VS Code and install these extensions (Ctrl+Shift+X):\n\n1. **ES7+ React/Redux/React-Native snippets** - dsznajder.es7-react-js-snippets\n2. **Prettier - Code formatter** - esbenp.prettier-vscode\n3. **ESLint** - dbaeumer.vscode-eslint\n4. **Thunder Client or REST Client** - rangav.vscode-thunder-client (for API testing)\n5. **PostgreSQL** - ckolkman.vscode-postgres\n6. **Python** - ms-python.python\n7. **Pylance** - ms-python.vscode-pylance\n8. **Docker** - ms-vscode.docker\n9. **Thunder Client** - rangav.vscode-thunder-client\n\n### Install Extensions via Command Line\n\n```bash\ncode --install-extension dsznajder.es7-react-js-snippets\ncode --install-extension esbenp.prettier-vscode\ncode --install-extension dbaeumer.vscode-eslint\ncode --install-extension rangav.vscode-thunder-client\ncode --install-extension ckolkman.vscode-postgres\ncode --install-extension ms-python.python\ncode --install-extension ms-python.vscode-pylance\ncode --install-extension ms-vscode.docker\n```\n\n## Step 3: Set Up Environment Variables\n\n1. **Open the project root folder in VS Code**\n2. **Create `.env` file** from `.env.example`:\n   - Press Ctrl+Shift+P → \"Copy File Path\"\n   - Or manually: Right-click `.env.example` → Copy\n   - Paste as `.env` in root folder\n\n3. **Edit `.env` file**:\n   ```bash\n   # Click on .env in Explorer\n   # Replace with your settings:\n   \n   NODE_ENV=development\n   PORT=5000\n   FRONTEND_URL=http://localhost:3000\n   \n   DATABASE_URL=postgresql://postgres:password@localhost:5432/soundwave\n   REDIS_URL=redis://localhost:6379\n   \n   JWT_SECRET=your_super_secret_key_min_32_characters_long_here\n   JWT_EXPIRE=7d\n   ```\n\n## Step 4: Database Setup\n\n### Option A: PostgreSQL Locally\n\n```bash\n# Open Terminal in VS Code (Ctrl+`)\n\n# 1. Connect to PostgreSQL\npsql -U postgres\n\n# 2. Create database and user\nCREATE DATABASE soundwave;\nCREATE DATABASE soundwave_test;\nCREATE USER soundwave_user WITH PASSWORD 'password';\nALTER ROLE soundwave_user SET client_encoding TO 'utf8';\nALTER ROLE soundwave_user SET default_transaction_isolation TO 'read committed';\nGRANT ALL PRIVILEGES ON DATABASE soundwave TO soundwave_user;\n\\q  # Quit psql\n```\n\n### Option B: Using Docker (Recommended)\n\n```bash\n# Install Docker from https://www.docker.com/products/docker-desktop\n\n# Start PostgreSQL container\ndocker run -d --name soundwave-postgres -e POSTGRES_PASSWORD=password -p 5432:5432 postgres:15\n\n# Start Redis container\ndocker run -d --name soundwave-redis -p 6379:6379 redis:latest\n\n# Verify containers are running\ndocker ps\n```\n\n## Step 5: Install Dependencies\n\nIn VS Code Terminal (Ctrl+`):\n\n```bash\n# Root directory dependencies\nnpm install\n\n# Backend Node.js dependencies\ncd backend/node-service\nnpm install\ncd ../..\n\n# Frontend dependencies (optional, for build)\ncd web-frontend\nnpm install\ncd ..\n\n# Python backend dependencies\ncd backend/python-service\npython -m venv venv\n\n# Activate virtual environment\n# On Windows:\nvenv\\Scripts\\activate\n\n# On macOS/Linux:\nsource venv/bin/activate\n\n# Install Python packages\npip install -r requirements.txt\n```\n\n## Step 6: Create VS Code Workspace\n\n1. **Save workspace**: File → Save Workspace As\n2. **Name it**: `soundwave.code-workspace`\n3. **Create workspace file** for multi-folder setup:\n\n```json\n{\n  \"folders\": [\n    {\n      \"path\": \".\",\n      \"name\": \"Root\"\n    },\n    {\n      \"path\": \"web-frontend\",\n      \"name\": \"Web Frontend\"\n    },\n    {\n      \"path\": \"backend/node-service\",\n      \"name\": \"Node Backend\"\n    },\n    {\n      \"path\": \"backend/python-service\",\n      \"name\": \"Python Backend\"\n    },\n    {\n      \"path\": \"mobile-app\",\n      \"name\": \"Mobile App\"\n    }\n  ],\n  \"settings\": {\n    \"[javascript]\": {\n      \"editor.defaultFormatter\": \"esbenp.prettier-vscode\",\n      \"editor.formatOnSave\": true\n    },\n    \"[python]\": {\n      \"editor.defaultFormatter\": \"ms-python.python\",\n      \"editor.formatOnSave\": true\n    }\n  }\n}\n```\n\n## Step 7: Configure Launch/Debug\n\n1. **Open Run and Debug**: Ctrl+Shift+D\n2. **Click \"Create a launch.json file\"**\n3. **Select \"Node.js\"** as environment\n4. **Replace with this configuration**:\n\n```json\n{\n  \"version\": \"0.2.0\",\n  \"configurations\": [\n    {\n      \"name\": \"Node Backend\",\n      \"type\": \"node\",\n      \"request\": \"launch\",\n      \"program\": \"${workspaceFolder}/backend/node-service/src/server.js\",\n      \"restart\": true,\n      \"console\": \"integratedTerminal\",\n      \"env\": {\n        \"NODE_ENV\": \"development\"\n      },\n      \"cwd\": \"${workspaceFolder}/backend/node-service\"\n    },\n    {\n      \"name\": \"Python Backend\",\n      \"type\": \"python\",\n      \"request\": \"launch\",\n      \"module\": \"uvicorn\",\n      \"args\": [\"main:app\", \"--reload\", \"--host\", \"0.0.0.0\", \"--port\", \"8000\"],\n      \"cwd\": \"${workspaceFolder}/backend/python-service\"\n    }\n  ],\n  \"compounds\": [\n    {\n      \"name\": \"All Services\",\n      \"configurations\": [\"Node Backend\", \"Python Backend\"]\n    }\n  ]\n}\n```\n\n## Step 8: Run the Project\n\n### Option A: Using Integrated Terminal (Recommended)\n\n```bash\n# 1. Open Terminal: Ctrl+`\n\n# 2. Split Terminal: Ctrl+Shift+5\n\n# Terminal 1 - Start Node.js Backend\ncd backend/node-service\nnpm run dev\n\n# Terminal 2 - Start Python Backend\ncd backend/python-service\nsource venv/bin/activate  # or venv\\Scripts\\activate on Windows\npython main.py\n\n# Terminal 3 - Start Web Frontend\ncd web-frontend\nnpm install\n# Open index.html in browser or use Live Server extension\n```\n\n### Option B: Using VS Code Run and Debug\n\n1. **Open Run and Debug**: Ctrl+Shift+D\n2. **Select configuration**: \"All Services\" (top dropdown)\n3. **Click Green Play Button** (F5)\n4. **Debugger will start both services**\n\n### Option C: Using npm scripts\n\n```bash\n# Terminal 1 - All services\nnpm run dev\n\n# Or individual services:\nnpm run dev:web      # Terminal 1\nnpm run dev:backend  # Terminal 2\n```\n\n## Step 9: Access the Application\n\nOnce all services are running:\n\n1. **Web Frontend**: http://localhost:3000\n2. **Node API**: http://localhost:5000/api/v1\n3. **Python Service**: http://localhost:8000\n4. **API Documentation**: http://localhost:5000/api/v1/docs\n\n## Step 10: Test API Endpoints\n\n### Using Thunder Client (VS Code Extension)\n\n1. Open Thunder Client: Ctrl+Shift+T\n2. Create New Request\n3. **Test Health Check**:\n   ```\n   GET http://localhost:5000/api/v1/health\n   ```\n\n### Using cURL in Terminal\n\n```bash\n# Health check\ncurl http://localhost:5000/api/v1/health\n\n# Get songs\ncurl http://localhost:5000/api/v1/songs\n\n# Search\ncurl \"http://localhost:5000/api/v1/search?q=artist\"\n```\n\n## Useful VS Code Shortcuts\n\n| Port Already in Use\n\n```bash\n# Kill process on port 5000 (Windows)\nnetstat -ano | findstr :5000\ntaskkill /PID <PID> /F\n\n# Kill process on port 5000 (macOS/Linux)\nlsof -i :5000\nkill -9 <PID>\n```\n\n### Module Not Found Error\n\n```bash\n# Clear and reinstall dependencies\ncd backend/node-service\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### PostgreSQL Connection Failed\n\n```bash\n# Check if PostgreSQL is running\nsudo systemctl status postgresql  # Linux\nbrew services list | grep postgres  # macOS\n\n# Start PostgreSQL\nsudo systemctl start postgresql   # Linux\nbrew services start postgresql    # macOS\n```\n\n### Python Module Not Found\n\n```bash\n# Activate virtual environment\ncd backend/python-service\nsource venv/bin/activate  # macOS/Linux\nvenv\\Scripts\\activate     # Windows\n\n# Reinstall dependencies\npip install -r requirements.txt\n```\n\n## VS Code Settings for Best Experience\n\nOpen Settings (Ctrl+,) and
