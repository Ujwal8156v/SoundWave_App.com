# 🎵 How to Run SoundWave Music Streaming App\n\n## 📋 Quick Start (5 Minutes)\n\nIf you want to get started quickly:\n\n```bash\n# 1. Clone the repo\ngit clone https://github.com/Ujwal8156v/soundwave-musicstream-app.git\ncd soundwave-musicstream-app\n\n# 2. Setup environment\ncp .env.example .env\n\n# 3. Install dependencies\nnpm install\n\n# 4. Start everything\nnpm run dev\n```\n\n✅ **Done!** Visit http://localhost:3000\n\n---\n\n## 📚 Complete Setup Guide (Detailed)\n\n### ✅ Step 1: Prerequisites Check\n\nVerify you have all required software:\n\n```bash\n# Check Node.js\nnode --version  # Should be v16 or higher\nnpm --version   # Should be v8 or higher\n\n# Check Python\npython3 --version  # Should be 3.9 or higher\n\n# Check PostgreSQL\npsql --version  # Should be 12 or higher\n\n# Check Redis\nredis-cli --version  # Should be installed\n```\n\n**If any is missing, install from:**\n- Node.js: https://nodejs.org/\n- Python: https://www.python.org/\n- PostgreSQL: https://www.postgresql.org/download/\n- Redis: https://redis.io/download\n\n---\n\n### ✅ Step 2: Clone Repository\n\n```bash\n# Navigate to desired location\ncd ~/projects  # or any folder you prefer\n\n# Clone the repository\ngit clone https://github.com/Ujwal8156v/soundwave-musicstream-app.git\n\n# Go into the directory\ncd soundwave-musicstream-app\n\n# View folder structure\nls -la\n```\n\n---\n\n### ✅ Step 3: Setup Environment Variables\n\n#### Create Root `.env` File\n\n```bash\n# Copy environment template\ncp .env.example .env\n\n# Edit with your editor (nano, vim, VS Code, etc.)\nnano .env\n```\n\n**Minimal `.env` for quick start:**\n\n```env\nNODE_ENV=development\nPORT=5000\nFRONTEND_URL=http://localhost:3000\n\nDATABASE_URL=postgresql://postgres:password@localhost:5432/soundwave\nREDIS_URL=redis://localhost:6379\n\nJWT_SECRET=your_super_secret_key_min_32_characters_long_here_change_this\nJWT_EXPIRE=7d\nJWT_REFRESH_EXPIRE=30d\n```\n\n#### Create Frontend `.env`\n\n```bash\ncd web-frontend\ncp .env.example .env.local\n```\n\n```env\nVITE_API_BASE_URL=http://localhost:5000/api/v1\nVITE_APP_NAME=SoundWave\nVITE_DEBUG=true\n```\n\n#### Create Backend Node `.env`\n\n```bash\ncd ../backend/node-service\ncp .env.example .env\n```\n\n```env\nNODE_ENV=development\nPORT=5000\nDATABASE_URL=postgresql://postgres:password@localhost:5432/soundwave\nREDIS_URL=redis://localhost:6379\nJWT_SECRET=your_super_secret_key_min_32_characters_long_here_change_this\n```\n\n#### Create Backend Python `.env`\n\n```bash\ncd ../python-service\ncp .env.example .env\n```\n\n```env\nENVIRONMENT=development\nAPP_PORT=8000\nDATABASE_URL=postgresql://postgres:password@localhost:5432/soundwave\nREDIS_URL=redis://localhost:6379\n```\n\nReturn to root:\n\n```bash\ncd ../../..\n```\n\n---\n\n### ✅ Step 4: Setup PostgreSQL Database\n\n#### On Mac:\n\n```bash\n# Start PostgreSQL\nbrew services start postgresql\n\n# Connect to PostgreSQL\npsql -U postgres\n```\n\n#### On Linux (Ubuntu):\n\n```bash\n# Start PostgreSQL\nsudo systemctl start postgresql\n\n# Connect to PostgreSQL\nsudo -u postgres psql\n```\n\n#### On Windows:\n\n```bash\n# Use pgAdmin or Command Prompt\npsql -U postgres\n```\n\n#### Create Database (all platforms):\n\nOnce in `psql` prompt:\n\n```sql\n-- Create main database\nCREATE DATABASE soundwave;\n\n-- Create test database\nCREATE DATABASE soundwave_test;\n\n-- List databases to confirm\n\\l\n\n-- Exit\n\\q\n```\n\n**Verify connection:**\n\n```bash\npsql -U postgres -d soundwave -c \"SELECT 1;\"\n# Should output: ?column?\n#     1\n```\n\n---\n\n### ✅ Step 5: Start Redis\n\n#### Option A: Using Docker (Recommended)\n\n```bash\n# Start Redis in Docker\ndocker run -d \\\n  --name soundwave-redis \\\n  -p 6379:6379 \\\n  redis:latest\n\n# Verify it's running\nredis-cli ping\n# Should output: PONG\n```\n\n#### Option B: Local Installation\n\n**Mac:**\n```bash\nbrew services start redis\nredis-cli ping  # Verify\n```\n\n**Linux:**\n```bash\nsudo systemctl start redis-server\nredis-cli ping  # Verify\n```\n\n**Windows:**\n```bash\nredis-server.exe\n# In another terminal\nredis-cli ping\n```\n\n---\n\n### ✅ Step 6: Install Dependencies\n\n#### A. Root Level\n\n```bash\ncd soundwave-musicstream-app\nnpm install\n```\n\n#### B. Frontend\n\n```bash\ncd web-frontend\nnpm install\ncd ..\n```\n\n#### C. Node.js Backend\n\n```bash\ncd backend/node-service\nnpm install\ncd ../..\n```\n\n#### D. Python Backend\n\n```bash\ncd backend/python-service\n\n# Create virtual environment\npython3 -m venv venv\n\n# Activate virtual environment\n# Mac/Linux:\nsource venv/bin/activate\n# Windows:\nvenv\\Scripts\\activate\n\n# Install dependencies\npip install -r requirements.txt\n\n# Deactivate for now\ndeactivate\n\ncd ../..\n```\n\n---\n\n### ✅ Step 7: Run the Project\n\n#### Option A: Run Everything at Once (Easiest)\n\n```bash\nnpm run dev\n```\n\nThis will start:\n- 🌐 **Web Frontend** on http://localhost:3000\n- 🔌 **Node.js API** on http://localhost:5000\n- 🐍 **Python Service** on http://localhost:8000\n\n**Wait 30-60 seconds for all services to start**\n\n---\n\n#### Option B: Run Services Separately (Better for Debugging)\n\nOpen **4 terminal windows/tabs**:\n\n**Terminal 1 - Redis (if not using Docker):**\n```bash\nredis-server\n```\n```\n* Ready to accept connections\n```\n\n---\n\n### ✅ Step 8: Verify Everything is Working\n\n#### Test API Health\n\n```bash\n# In new terminal\ncurl http://localhost:5000/api/health\n```\n\nShould return:\n```json\n{\n  \"status\": \"API is running\",\n  \"timestamp\": \"2024-01-15T10:30:00Z\"\n}\n```\n\n#### Test Database Connection\n\n```bash\n# Test PostgreSQL\npsql -U postgres -d soundwave -c \"SELECT version();\"\n\n# Test Redis\nredis-cli ping\n```\n\n#### Access the Application\n\nOpen your browser and visit:\n\n```\nhttp://localhost:3000\n```\n\n✅ You should see the SoundWave homepage!\n\n---\n\n## 🎮 Using the Application\n\n### Homepage\n\n```\nhttp://localhost:3000\n```\n\n- Click **\"Explore Now\"** to browse songs\n- Click **\"Login\"** to create an account\n\n### Sign Up\n\n1. \"Port 3000 already in use\"\n\n```bash\n# Find process using port\nlsof -i :3000\n\n# Kill process\nkill -9 <PID>\n\n# Or use different port\nPORT=3001 npm run dev\n```\n\n### Error: \"Cannot connect to PostgreSQL\"\n\n```bash\n# Check if PostgreSQL is running\npsql -U postgres -c \"SELECT 1;\"\n\n# If error, start PostgreSQL\nbrew services start postgresql  # Mac\nsudo systemctl start postgresql  # Linux\n\n# Verify database exists\npsql -U postgres -l | grep soundwave\n```\n\n### Error: \"Cannot connect to Redis\"\n\n```bash\n# Check if Redis is running\nredis-cli ping\n\n# If error, start Redis\nbrew services start redis  # Mac\nsudo systemctl start redis-server  # Linux\n\n# Or using Docker\ndocker run -d -p 6379:6379 redis:latest\n```\n\n### Error: \"API not responding\"\n\n```bash\n# Test API\ncurl http://localhost:5000/api/health\n\n# Check if Node service is running\nlsof -i :5000\n\n# Check backend logs\ncd backend/node-service\nnpm run dev\n```\n\n### Error: \"Frontend not loading\"\n\n```bash\n# Clear browser cache\n# Ctrl + Shift + Delete (or Cmd + Shift + Delete on Mac)\n\n# Or use private/incognito window\n# Visit http://localhost:3000\n\n# Check if frontend is running\nlsof -i :3000\n```\n\n### Python service not starting\n\n```bash\n# Activate virtual environment\ncd backend/python-service\nsource venv/bin/activate  # Mac/Linux\n# or\nvenv\\Scripts\\activate  # Windows\n\n# Install dependencies again\npip install -r requirements.txt\n\n# Run\npython main.py\n```\n\n---\n\n## 📊 Verify All
