# 🔧 Environment Configuration Guide\n\n## Overview\n\nThis guide explains how to configure all environment variables for the SoundWave Music Streaming App across all services.\n\n---\n\n## 📁 Environment Files Location\n\n```\nsoundwave-musicstream-app/\n├── .env                           # Root environment (main config)\n├── web-frontend/\n│   └── .env.local                # Frontend environment\n├── backend/\n│   ├── node-service/\n│   │   └── .env                  # Node.js service\n│   └── python-service/\n│       └── .env                  # Python service\n└── mobile-app/\n    └── .env                      # Mobile environment\n```\n\n---\n\n## 📋 Step 1: Root Environment Configuration\n\n### Create Root `.env` File\n\n```bash\ncd soundwave-musicstream-app\ncp .env.example .env\nnano .env  # or use your preferred editor\n```\n\n### Root `.env` Template\n\n```env\n# ============================================\n# APPLICATION CONFIGURATION\n# ============================================\n\n# Environment type\nNODE_ENV=development  # Options: development, staging, production\n\n# Application Port\nPORT=5000\n\n# Frontend URLs\nFRONTEND_URL=http://localhost:3000\nMOBILE_APP_ID=com.soundwave.music\n\n# API Base URL\nAPI_BASE_URL=http://localhost:5000/api/v1\n\n# ============================================\n# DATABASE CONFIGURATION\n# ============================================\n\n# PostgreSQL Connection String\n# Format: postgresql://username:password@host:port/database\nDATABASE_URL=postgresql://postgres:password@localhost:5432/soundwave\n\n# PostgreSQL Test Database\nDATABASE_TEST_URL=postgresql://postgres:password@localhost:5432/soundwave_test\n\n# Database SSL (use 'require' for production)\nDB_SSL=disable  # Options: disable, require, prefer\n\n# Database Connection Pool\nDB_POOL_MIN=5\nDB_POOL_MAX=20\n\n# ============================================\n# REDIS CONFIGURATION\n# ============================================\n\n# Redis Connection String\n# Format: redis://[:password@]host:port\nREDIS_URL=redis://localhost:6379\n\n# Redis Database Number (0-15)\nREDIS_DB=0\n\n# Redis TTL (Time To Live) in seconds\nREDIS_TTL=86400  # 24 hours\n\n# ============================================\n# JWT AUTHENTICATION\n# ============================================\n\n# JWT Secret (minimum 32 characters, use strong random string)\nJWT_SECRET=your_super_secret_key_min_32_characters_long_here_change_this_in_production\n\n# JWT Expiration\nJWT_EXPIRE=7d        # 7 days\nJWT_REFRESH_EXPIRE=30d  # 30 days\n\n# Refresh Token Secret\nJWT_REFRESH_SECRET=your_refresh_secret_key_min_32_characters_long_here\n\n# ============================================\n# THIRD-PARTY API KEYS\n# ============================================\n\n# Spotify API\nSPOTIFY_CLIENT_ID=\nSPOTIFY_CLIENT_SECRET=\nSPOTIFY_REDIRECT_URI=http://localhost:5000/api/v1/auth/spotify/callback\n\n# YouTube API\nYOUTUBE_API_KEY=\n\n# Last.fm API\nLAST_FM_API_KEY=\n\n# Genius API (Lyrics)\nGENIUS_API_KEY=\n\n# SoundCloud API\nSOUNDCLOUD_CLIENT_ID=\n\n# ============================================\n# FILE STORAGE (AWS S3)\n# ============================================\n\n# AWS Configuration\nAWS_ACCESS_KEY_ID=\nAWS_SECRET_ACCESS_KEY=\nAWS_S3_BUCKET=soundwave-music\nAWS_REGION=us-east-1\nAWS_S3_ENDPOINT=\n\n# File Upload Settings\nMAX_FILE_SIZE=52428800  # 50MB in bytes\nALLOWED_MUSIC_FORMATS=mp3,wav,flac,m4a,aac\n\n# ============================================\n# EMAIL CONFIGURATION\n# ============================================\n\n# SMTP Settings\nSMTP_HOST=smtp.gmail.com\nSMTP_PORT=587\nSMTP_USER=your-email@gmail.com\nSMTP_PASS=your-app-password\n\n# Email Settings\nEMAIL_FROM=noreply@soundwave.com\nEMAIL_FROM_NAME=SoundWave\n\n# ============================================\n# LOGGING CONFIGURATION\n# ============================================\n\n# Log Level\nLOG_LEVEL=info  # Options: error, warn, info, debug, silly\n\n# Log File Path\nLOG_FILE=logs/app.log\n\n# Log to Console\nLOG_CONSOLE=true\n\n# ============================================\n# SECURITY CONFIGURATION\n# ============================================\n\n# Bcrypt Rounds (Higher = more secure but slower)\nBCRYPT_ROUNDS=10\n\n# Login Attempt Settings\nMAX_LOGIN_ATTEMPTS=5\nLOCK_TIME=15m  # 15 minutes\n\n# CORS Origins (comma-separated)\nCORS_ORIGINS=http://localhost:3000,http://localhost:8000,http://localhost:8080\n\n# Rate Limiting\nRATE_LIMIT_WINDOW=15m  # 15 minutes\nRATE_LIMIT_MAX_REQUESTS=100  # requests per window\n\n# ============================================\n# MONITORING & ANALYTICS\n# ============================================\n\n# Sentry (Error Tracking)\nSENTRY_DSN=\n\n# Analytics\nGOOGLE_ANALYTICS_ID=\n\n# ============================================\n# FEATURE FLAGS\n# ============================================\n\n# Enable/Disable Features\nENABLE_SPOTIFY_SYNC=true\nENABLE_YOUTUBE_SYNC=true\nENABLE_DOWNLOAD=true\nENABLE_OFFLINE_MODE=true\nENABLE_SOCIAL_FEATURES=true\nENABLE_RECOMMENDATIONS=true\n\n# ============================================\n# WORKER/QUEUE CONFIGURATION\n# ============================================\n\n# RabbitMQ\nRABBITMQ_URL=amqp://guest:guest@localhost:5672\n\n# Celery (Python)\nCELERY_BROKER=redis://localhost:6379/1\nCELERY_BACKEND=redis://localhost:6379/2\n```\n\n---\n\n## 📋 Step 2: Frontend Environment Configuration\n\n### Create Web Frontend Spotify API\n\n**Steps:**\n1. Go to [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)\n2. Log in or create account\n3. Click \"Create an App\"\n4. Accept terms and create app\n5. Copy **Client ID** and **Client Secret**\n\n**Add to `.env`:**\n```env\nSPOTIFY_CLIENT_ID=your_client_id_here\nSPOTIFY_CLIENT_SECRET=your_client_secret_here\nSPOTIFY_REDIRECT_URI=http://localhost:5000/api/v1/auth/spotify/callback\n```\n\n---\n\n### 2. YouTube API\n\n**Steps:**\n1. Go to [Google Cloud Console](https://console.cloud.google.com)\n2. Create new project\n3. Enable \"YouTube Data API v3\"\n4. Go to Credentials\n5. Create API key\n6. Copy the key\n\n**Add to `.env`:**\n```env\nYOUTUBE_API_KEY=your_api_key_here\n```\n\n---\n\n### 3. Last.fm API\n\n**Steps:**\n1. Go to [Last.fm API](https://www.last.fm/api)\n2. Click \"Get API Account\"\n3. Fill in form and create application\n4. Copy **API Key**\n\n**Add to `.env`:**\n```env\nLAST_FM_API_KEY=your_api_key_here\nLAST_FM_API_SECRET=your_secret_here\n```\n\n---\n\n### 4. Genius API (Lyrics)\n\n**Steps:**\n1. Go to [Genius API](https://genius.com/api-clients)\n2. Create New API Client\n3. Generate access token\n4. Copy token\n\n**Add to `.env`:**\n```env\nGENIUS_API_KEY=your_access_token_here\n```\n\n---\n\n### 5. AWS S3 (File Storage)\n\n**Steps:**\n1. Go to [AWS Console](https://console.aws.amazon.com)\n2. Create IAM user with S3 permissions\n3. Generate access keys\n4. Create S3 bucket\n\n**Add to `.env`:**\n```env\nAWS_ACCESS_KEY_ID=your_access_key_here\nAWS_SECRET_ACCESS_KEY=your_secret_key_here\nAWS_S3_BUCKET=soundwave-music\nAWS_REGION=us-east-1\n```\n\n---\n\n### 6. Gmail SMTP (Email)\n\n**Steps:**\n1. Enable 2-factor authentication in Gmail\n2. Go to [App Passwords](https://myaccount.google.com/apppasswords)\n3. Select Mail and Windows Computer\n4. Generate app password\n5. Copy the 16-character password\n\n**Add to `.env`:**\n```env\nSMTP_HOST=smtp.gmail.com\nSMTP_PORT=587\nSMTP_USER=your-email@gmail.com\nSMTP_PASS=your-app-password-here\nEMAIL_FROM=noreply@soundwave.com\n```\n\n---\n\n## 🔐 Security Best Practices\n\n### 1. JWT Secret Generation\n\n**Generate strong JWT secret:**\n\n```bash\n# Mac/Linux\nnode -e \"console.log(require('crypto').randomBytes(32).toString('hex'))\"\n\n# Or using Python\npython3 -c \"import secrets; print(secrets.token_hex(32))\"\n\n# Or using OpenSSL\nopenssl rand -hex 32\n```\n\n**Add to `.env`:**\n```env\nJWT_SECRET=generated_random_string_here\n```\n\n### 2. Bcrypt Rounds\n\n```env\n# Development (faster)\nBCRYPT_ROUNDS=10\n\n# Production (more secure but slower)\nBCRYPT_ROUNDS=12\n```\n\n### 3. Environment Variable Naming Convention\n\n```env\n# Public (frontend accessible)\nVITE_API_BASE_URL=http://localhost:5000/api/v1\n\n# Private (backend only)\nJWT_SECRET=super_secret_value\nDATABASE_URL=postgresql://...\n```\n\n---\n\n## ✅ Verification Checklist\n\nAfter setting up environment variables:\n\n```bash\n# 1.
