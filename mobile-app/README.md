# SoundWave Mobile App

Expo mobile app for the SoundWave music streaming project.

## Run

```powershell
cd mobile-app
npm install
npm run start
```

Use Expo Go on your phone, or run:

```powershell
npm run android
npm run ios
npm run web
```

For Android emulator, set `EXPO_PUBLIC_API_BASE_URL` to `http://10.0.2.2:5000/api/v1`.
